BUG-001

Cart: Quantity field accepts negative values and reduces order total

High
Environment
Chrome 130 · Windows 11 · Demo e-commerce site
Reproducibility
Always (5/5 attempts)
Reported
Practice project · 2025
Steps to Reproduce
  1. Open the shop homepage in a new private window.
  2. Add any product (e.g. “Blue Notebook – ₹100”) to the cart.
  3. Go to the Cart page.
  4. In the Quantity field, clear the value and type -1, then press Tab or click outside.
  5. Observe the order total and item quantity.
Expected Result Quantity should not accept values less than 1. System should show a validation message or reset to 1.
Actual Result Quantity becomes -1 and the order total is reduced. User can proceed toward checkout with invalid quantity.
BUG-002

Login: Error message not shown when wrong password is entered

Medium
Environment
Firefox 131 · macOS · Practice login page
Reproducibility
Always
Reported
Practice project · 2025
Steps to Reproduce
  1. Navigate to the login page.
  2. Enter a valid email address.
  3. Enter an incorrect password.
  4. Click the “Login” button.
Expected Result A clear error message such as “Incorrect email or password” should appear near the form.
Actual Result Page reloads or stays the same with no visible error message. User has no feedback that login failed.
BUG-003

Search: Special characters cause 500 error instead of empty results

Critical
Environment
Chrome · Android mobile view · Demo search page
Reproducibility
Always
Reported
Practice project · 2025
Steps to Reproduce
  1. Open the website search bar.
  2. Enter the string: %%%''' OR 1=1 --
  3. Press Enter / click Search.
Expected Result Search should return “No results found” or safely handle the input without crashing.
Actual Result Server returns HTTP 500 Internal Server Error. Page shows a generic error screen.
